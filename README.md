# Logistique Urbain – Système de Gestion
Application de gestion de livraisons urbaines.

## Installation
1. Cloner le dépôt
2. Installer les dépendances : `pip install -r requirements.txt`
3. Lancer : `python logistique.py`

## Génération de l'exécutable
`pyinstaller --onefile --windowed --name Logistique logistique.py`
